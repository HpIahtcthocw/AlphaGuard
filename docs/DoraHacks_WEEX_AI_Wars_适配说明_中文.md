## 推荐参赛项目

使用本目录的 **Firebreak（个人投资研究与风险守门 Agent）**，不另起项目。

匹配理由：

1. 已有行情适配、策略回测、样本外审计和风险门禁闭环。
2. Agent 只能理解任务、选择白名单工具，不能越权修改风险规则。
3. 默认纸面交易，证据不足时返回 `BLOCKED`，不会创建订单意图。
4. 适合包装成“可审计的 AI 交易研究/风控 Agent”，避免宣称自动赚钱或无监督实盘。

## 面向 WEEX 的演示切口

演示主题：**AI 交易 Agent 先验证证据，再决定是否允许进入模拟交易。**

建议 3 分钟路径：

1. 输入一条低波动 ETF/加密资产轮动策略验证任务。
2. 展示数据来源、数据质量、回测与样本外审计。
3. 展示五段 Walk-forward 和成本/回撤检查。
4. 让确定性风险门禁给出 `BLOCKED`，说明合成演示数据、独立数据源和模拟盘持续验证尚不足。
5. 展示完整 Trace，并确认没有生成订单意图。

若官方赛题要求连接 WEEX API，再增加一个**只读行情适配器**；在规则确认前不接真实下单接口。
