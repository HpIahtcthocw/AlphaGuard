# 待确认决策

1. **市场范围**：是否确认首版只做中国股票/ETF，是否需要港股或美股？
2. **部署方式**：是否接受本地 Docker/SQLite，还是需要 NAS、云服务器或手机访问？
3. **数据预算**：哪些数据源已有权限？是否允许使用 TuShare Pro、券商导出和商业数据？
4. **账户模式**：先做一个账户，还是一开始支持多个账户/家庭账户？
5. **策略类型**：首个可验证策略是动量、均线、ETF 轮动、因子选股，还是用户已有策略？
6. **执行边界**：是否明确首版只做模拟盘和“人工确认后的实盘计划”？
7. **Agent 模型**：优先本地模型、OpenAI 兼容 API，还是允许多供应商路由？
8. **界面优先级**：先做 CLI/Notebook、Web 工作台，还是先做手机友好的简洁页面？
9. **合规与隐私**：账户与流水是否必须完全不出本机？
10. **验收样本**：是否能提供一份脱敏交易流水和一组允许使用的历史数据作为固定验收集？
