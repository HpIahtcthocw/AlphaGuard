# 研究与决策规格

## 1. 研究卡片

每个研究想法必须先形成研究卡片：

- 假设：可证伪、可量化的陈述。
- 经济直觉：为什么可能存在风险溢价或行为偏差。
- 标的范围：市场、资产类别、流动性和排除规则。
- 数据：字段、频率、时间范围、来源和许可。
- 失效条件：何时认为假设不成立。
- 实验计划：基准、成本、切分、参数、稳健性检查。
- 决策门槛：达到什么证据才进入纸面交易。

## 2. 回测最低标准

- 严格按时间切分，禁止使用未来信息。
- 明确复权、停牌、涨跌停、成交量和可交易性。
- 至少包含佣金、印花税、滑点、最小成交单位和现金约束。
- 报告训练内、验证外、测试外和滚动/走样结果。
- 除收益外必须报告最大回撤、波动率、夏普、Sortino、换手、胜率、盈亏比、容量和基准差。
- 做参数敏感性、子区间、行业/标的留出和简单基线比较。
- 结果不允许只展示最优参数；必须展示搜索空间和失败实验。

## 3. 交易计划格式

```json
{
  "thesis": "结构化、可证伪的交易理由",
  "evidence": [{"source": "...", "as_of": "...", "quote_or_metric": "..."}],
  "instrument": "...",
  "side": "buy|sell|rebalance",
  "target_weight": 0.0,
  "entry_rule": "...",
  "position_limit": 0.0,
  "max_loss": 0.0,
  "invalidation": "...",
  "expiry": "...",
  "risks": ["..."],
  "risk_check": {"status": "pass|fail|manual_review", "reasons": []},
  "approval": {"required": true, "status": "pending"}
}
```

## 4. 决策日志

每次实际操作都记录：当时看到的事实、当时的判断、替代方案、批准人、执行价格、结果和复盘标签。复盘不允许用事后信息改写原始判断。
