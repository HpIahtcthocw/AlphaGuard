# 风险与合规门禁

## 1. 资金与执行门禁

- 默认只允许模拟账户。
- 实盘适配器默认关闭，启用需要显式配置、二次确认和可回滚开关。
- 每笔订单必须有对应的已批准 `OrderIntent`，禁止 UI 或 Agent 直接构造订单。
- 单标的、单行业、组合回撤、日损失、现金、价格偏离、订单频率和流动性都有硬上限。
- 订单过期、重复、部分成交、撤单失败和交易时段异常必须进入人工复核。

## 2. 数据与隐私

- 密钥只读环境变量/密钥存储，不进入日志、提示词或仓库。
- 券商流水、账户余额和个人信息默认本地存储，脱敏后才允许外发给模型或第三方 API。
- 每个数据源记录许可、更新时间、字段口径和可否用于回测/再分发。
- 原始数据只追加不覆盖，修订通过新版本和差异记录完成。

## 3. Agent 安全

- 工具按最小权限授予：研究 Agent 不得访问账户密钥，风控 Agent 不得修改策略，执行 Agent 不得修改计划。
- 外部内容视为不可信输入，防止提示注入和恶意链接。
- LLM 只能引用已检索来源；缺来源时必须标记未知。
- 高影响动作采用双重确认：风险检查通过 + 用户确认。
- 所有工具调用、输入摘要、输出、错误和人工覆盖都写入审计表。

## 4. 合规边界

项目仅作为个人研究、记录和辅助决策工具，不向第三方提供投资顾问服务，不承诺收益。上线前需根据实际地区、券商接口、数据许可和税务规则进行专业合规审查。
