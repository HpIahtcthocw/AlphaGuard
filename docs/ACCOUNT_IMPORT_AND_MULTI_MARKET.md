# 账户导入与中美市场支持

## 已实现

- 浏览器本地导入 CSV，不上传原文件。
- 自动识别持仓快照或交易流水。
- 支持常见中英文列名。
- 自动识别中国、美国和香港市场代码。
- 支持 CNY、USD 和 HKD 字段；美元资产使用用户明确填写的 USD/CNY 汇率折算。
- 持仓快照导入后立即更新组合列表、总市值、币种状态和现金比例。
- 交易流水保存到独立本地存储，等待账本服务进行成本和成交核对。
- 提供中美持仓、交易流水示例及可下载模板。

## 为什么不自动抓取实时汇率

导入属于可复现的账本动作。系统必须记录用户使用的明确汇率或数据快照，而不是静默使用一个会变化的在线价格。未来实时展示可以使用市场数据，但账本入账仍需要保存当时使用的汇率和来源。

## 券商适配方式

第一层使用通用 CSV 模板；第二层根据券商导出表头自动识别；第三层为常用券商编写独立适配器。适配器只负责字段转换，不能修改数量、价格、费用或币种。

计划适配顺序：

1. 通用持仓与交易模板。
2. Interactive Brokers Flex/CSV。
3. 富途、老虎等支持中美资产的导出格式。
4. 国内券商成交与交割单。

具体券商格式需要用户提供脱敏样本后才能安全实现，不能根据猜测硬编码。

## 美股额外要求

- 证券主数据区分 ticker、交易所、币种、资产类型和时区。
- 处理拆股、分红、退市、并购和 ticker 变更。
- 组合报告同时展示本币市值与人民币折算市值。
- 收益归因分离证券收益和汇率收益。
- 交易日历与中国市场独立，跨市场任务不能假设同步开盘。
- 税务信息只记录，不自动提供税务结论。

## 金融 Skills 接入

`equity-research` 用于美股个股的预期、财务、估值、价格和投资论据；`macro-rates-monitor` 用于美元利率、通胀、收益率曲线与金融条件。两者都是只读研究能力，必须输出来源和时间，不能直接生成或修改订单。

当前运行环境没有这些 Skills 所需的专业数据 MCP 工具，因此界面只展示能力入口和权限状态，不生成虚假实时数据。
