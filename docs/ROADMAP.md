# 实施路线图

## 当前状态：v0.7 Early Alpha

- Phase 0 的产品边界和确定性闭环已完成首轮冻结。
- Phase 1 已完成持仓快照，交易流水、分红、税费和公司行动账本仍未完成。
- Phase 2 已完成可运行回测、三基线、样本外切分和数据质量报告；真实历史数据快照与完整稳健性验证仍未完成。
- `S-003` 多空突破策略已完成因子化研究信号版；尚未进入多空回测和执行。
- 已完成多标的横截面扫描和研究组合构建。
- 已完成研究级多空回测近似模型，以及 A 股/美股交易单位、做空许可和涨跌停近似规则门禁；仍需按券商和市场校准，不能用于生产保证金判断。
- 已完成标准 OHLCV CSV 数据集契约、质量检查和指纹；仍需接入 point-in-time 复权与公司行动数据。
- 已建立 `PIO-EXP-001` 个人投资实验协议：固定参数、基线、样本外/walk-forward 证据和研究门禁；默认合成数据结果不会进入纸面或实盘。
- 实验已支持经契约校验的真实/延迟 OHLCV CSV 重放，并优先使用完整复权收盘价；仍需真实供应商对账和连续纸面运行。
- 已增加 Alpaca 订单状态同步，但成交、现金流水和持仓账本仍未自动从券商回报重建。
- Phase 3 已完成本地纸面闭环和 Alpaca Paper 提交适配；券商回报同步与连续四周验收仍未完成。
- Phase 4 尚未实现运行时 Agent。
- Phase 5 只有受锁定的 Alpaca 适配器代码，未通过真实资金生产验收。

## Phase 0：方案冻结

- 确认市场、账户、部署位置、数据预算和自动化边界。
- 确认开源许可证策略、数据许可台账和安全威胁模型。
- 输出领域模型、接口契约和最小验收数据集。

## Phase 1：资产账本 MVP

- 导入 CSV/券商成交单。
- 账户、持仓、现金、费用、分红、公司行动和基准。
- 组合收益、回撤、暴露和可导出报告。
- 交付标准：用一份脱敏真实流水完成对账，差异可解释。

## Phase 2：研究与回测 MVP

- 数据源适配器、数据质量报告和 Parquet 快照。
- 规则策略、基线、成本模型、回测报告和实验登记。
- 策略来源注册、许可证检查、版本升级和淘汰状态机。
- 参数邻域、走样验证、留出资产和失败场景报告。
- 交付标准：同一快照可复现；至少捕获一类前视偏差测试。

## Phase 3：纸面交易与风险门禁

- 信号转交易计划，组合约束，模拟订单和成交回写。
- 日终任务、异常告警、决策日志和复盘。
- 交付标准：连续 4 周纸面运行，无未解释的账本/订单不一致。

## Phase 4：受约束 Agent

- Data Steward、Researcher、Backtest Auditor、Risk Officer 四个角色。
- 工具白名单、结构化输出、来源引用、提示词/模型版本和审计。
- 交付标准：Agent 不能绕过风控；对缺数据、冲突数据和不确定性正确拒答。

## Phase 5：可选实盘适配器

- 只接入一个经过确认的券商/模拟券商接口。
- 先只读，再人工确认下单，再考虑有限自动化。
- 交付标准：杀开关、订单幂等、断线恢复、权限审计和回滚演练通过。

## 推荐节奏

以单人开发为例，Phase 0 用 2-4 天，Phase 1 用 1-2 周，Phase 2 用 2-3 周，Phase 3 用 1-2 周，Phase 4 用 2-3 周。Phase 5 不设承诺日期，以安全验收结果为准。
