Agent-accessible surface

Real actions, described in webmcp.json, called by agents

An agent reads llms.txt, loads the typed contract in webmcp.json, then calls the endpoints below. No UI clicks — every action is real, structured and auditable.

audit_strategy

POST /api/goai/audit-demo

Run the full guarded audit: plan with the LLM, then apply deterministic data, walk-forward and production gates. Returns a verdict and an auditable tool trace.

PLAN_ONLYVETO

run_demo_backtest

GET /api/research/demo-backtest

Reproducible backtest on explicitly-marked synthetic data with baselines and out-of-sample metrics.

READ_ONLY

validate_dataset

POST /api/research/datasets/ohlcv/validate

Validate an OHLCV CSV against a dataset contract — errors, warnings and a unique data fingerprint.

READ_ONLY

market_rules

GET /api/research/market-rules

Read trading-unit, short-selling and price-limit rules for US / CN markets before proposing an order.

READ_ONLY

run_experiment

POST /api/research/experiments/personal/run

Validate a user CSV and replay the fixed, research-only experiment protocol with the same guardrails.
